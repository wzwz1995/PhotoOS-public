# PhotoOS 安装说明（给拿到这个压缩包的人）

PhotoOS 是一个**本地**的个人摄影管理工具：索引、精选、按内容找照片、按人找照片、
主题与打包。照片始终在你自己硬盘上，**它不上传任何东西、也不改动你的原片**。

> 本文是 **wheel + install.ps1** 路线。若你拿到的是 `PhotoOS-<版本>-win64.zip` 绿色包，
> 直接解压双击 `PhotoOS.exe`，不需要 Python；见根 README 的「下载」。

---

## 一、你需要准备什么

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Windows 10 / 11（64 位） | 目前只在这一个平台上验过 |
| Python | **3.12** | 免费，约 25 MB：[python.org 下载](https://www.python.org/downloads/release/python-31210/)。安装时**勾上 "Add python.exe to PATH"** |
| 磁盘 | 数据目录约等于照片库的 **10%**（缩略图与预览） | 2 万张照片大约 4 GB |
| 照片 | 放在本机硬盘或移动硬盘上 | 移动硬盘拔掉时仍能浏览索引与缩略图，只是打不开原图 |

> **没有 Python 能不能用？** 现在还不能。这一版是"源码 + 一键脚本"的形态，
> 需要机器上有 Python 3.12。装一次，以后不用管它。

## 二、装（两条命令，或双击脚本）

1. 把压缩包解到任意目录（例如 `C:\PhotoOS-install`），里面应该有：
   - `photoos-0.1.0-py3-none-any.whl`（程序本体）
   - `install.ps1`（安装脚本）
   - `安装说明.md`（本文件）

2. 在那个目录里**右键 → 在终端中打开**，然后：

```powershell
# 基础版：浏览、精选、主题、打包、说明页。不需要任何模型。
.\install.ps1 -Wheel .\photoos-0.1.0-py3-none-any.whl
```

```powershell
# 想用人脸分人和"中文找照片"，加 -WithAI（多下约 500 MB 依赖）
.\install.ps1 -Wheel .\photoos-0.1.0-py3-none-any.whl -WithAI
```

> 如果提示"禁止运行脚本"，用这一行代替（只对本次生效）：
> `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Wheel .\photoos-0.1.0-py3-none-any.whl`

装完脚本会问你要不要立刻启动。之后随时可以双击
`%LOCALAPPDATA%\PhotoOS\app\start-photoos.cmd` —— 它会起服务并打开浏览器
（地址固定是 `http://127.0.0.1:8760`，只监听本机，同一局域网的别人访问不到）。

**关掉那个黑窗口 = 停止 PhotoOS。**

---

## 三、装完先做这三件事

1. **添加库**：「照片库」页 → 添加库 → 指向你的照片目录。
   这一步**只读**：PhotoOS 不移动、不改名、不删除任何文件。
   （它会在照片目录里写**一个**文件 `.photoos\library.json` 用来认盘；不想要可以不加 `--write-marker`。）
2. **建索引**：「维护」页 → 完整索引。2 万张大约十几分钟到一小时（取决于硬盘），
   可以随时暂停、关掉再续。
3. **看一眼「说明」页**：每个功能解决什么、怎么用、有哪些真实限制，都在那里。

想用 AI 功能（分人、中文找照片）的话，还要先下模型（一次性的）：

```powershell
& "$env:LOCALAPPDATA\PhotoOS\app\venv\Scripts\python.exe" -m photoos ai fetch-model --engine all
```

| 模型 | 大小 | 用途 |
| --- | ---: | --- |
| CLIP ViT-B/32（ONNX，仅视觉塔） | 335 MB | 场景划分与相似度（**不能用文字搜图**） |
| EmbeddingGemma 2 | 1,455 MB | 用中文词找照片 |
| YuNet + SFace | 37 MB | 人脸检测与特征（分人） |

## 四、你的照片和数据在哪

| 东西 | 位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\PhotoOS\app`（venv 在里面，删掉它不会丢数据） |
| 数据（索引库、缩略图、人物、主题、打包产物） | `%LOCALAPPDATA%\PhotoOS\data` |
| **原片** | **原地不动**，PhotoOS 只读它们 |

**备份**：备份 `data` 目录就等于备份了整个索引；原片要单独备（两者合起来才是完整的）。
**换机器**：把 `data` 目录拷过去，重装一次程序，用「维护 → 重新绑定」指回照片盘即可
（数据库里不存盘符，存的是"卷指纹 + 相对路径"，所以换盘符也能认回来）。

## 五、常见问题

**Q：Windows 说"未知发布者" / SmartScreen 拦住了。**
A：脚本是明文 PowerShell，可以直接用记事本打开看它做了什么（只有四件事：
建 venv、pip 装包、初始化数据目录、生成一个启动器）。不放心就照第二节手工敲那几条命令。

**Q：装的时候很慢 / 卡住。**
A：第一次要下 100~600 MB 的依赖（取决于是否 `-WithAI`）。国内网络建议先设镜像：
`$env:PIP_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"`。
模型下载同理：程序内已默认走 `hf-mirror.com`。

**Q：没有 NVIDIA 显卡能用吗？**
A：能。默认装的是 CPU 版（`onnxruntime`），慢一些但完全可用。
有显卡的话，把 `onnxruntime` 换成 `onnxruntime-gpu==1.25.1` 与对应 CUDA 运行库
（版本组合与已知坑见项目文档「AI 子系统」）。

**Q：会动我的照片吗？**
A：不会。这是它的第一条铁律：**原片永不被碰**。唯一的写操作是
`photoos import`（你自己主动发起，且默认只预演），以及照片目录里那一个
`.photoos\library.json` 认盘标记。

**Q：想卸载。**
A：删掉安装目录 `%LOCALAPPDATA%\PhotoOS\app` 即可；数据在 `%LOCALAPPDATA%\PhotoOS\data`，
是否删除由你决定。照片不受影响。
