找照片

按画面内容适合找「某类照片」； 按时间 / 地点 / 场次适合找「某一次拍摄」，结果精确、可复现。

人物

系统只能提出「这里有一簇可能是同一个人的脸」，它不知道那是谁。 你命名并确认几张之后，它会拿你的判断去找更多 —— 你确认得越多，它越准。

主题

主题是你主动创建的长期作品集合，不受时间、地点或场次限制 —— 「蓝调时刻」可以横跨不同年份与城市。同一张照片可以同时属于多个主题。

加入或移出只改变数据库关系，不移动、不复制、不删除任何照片。 照片硬盘离线时，主题列表、封面与排序仍然可用。

导入新照片

照片会复制进库，并按拍摄时间和地点归入 <城市>\<时段>\；源文件只读。 先预演确认落点，再执行。

预演只检查前 N 个文件；确认执行会处理全部。没有 GPS 时填强制城市。 「选目录…」仅桌面版可用；浏览器里请粘贴目录路径。

从手机导入（收件箱）正在读取…

把手机照片复制到收件箱，等文件不再变化后再导入。 默认只读；勾选清理后只删已安全入库的副本，手机不动。

从手机导入（ADB，可选）批量拉取；需要手机打开 USB 调试

用 adb 把手机目录拉到收件箱，手机文件只读。没装 adb 不影响上面的收件箱导入。

废片清理标记后统一移入回收站（可还原）

只清理你在照片详情里标记为废片的照片：移入 Windows 回收站，可还原，不永久删除。 命中精选或主题的照片会跳过。
