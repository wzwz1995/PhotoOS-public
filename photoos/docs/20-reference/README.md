## 复算这些文档里的数字

```powershell
powershell -ExecutionPolicy Bypass -File docs\20-reference\verify-docs.ps1
```

`verify-docs.ps1` / `verify_docs.py` 是**只读**的：数据库一律 `mode=ro` 打开，
不遍历照片盘，不写任何文件。它会打印出文档里引用的基线数字
（git HEAD、表/索引数、行数统计、CLI 命令数、接口 operation 数……）。

## 三条使用约定

1. **代码是唯一真源。** 本目录是某一时刻的快照；与代码冲突时以代码为准，并顺手改文档。
2. **改代码就改这里对应的那一句**，保留证据标记。标记从 `【实测】` 退回 `【推断】`
   比留着过期结论安全。
3. **图用 Mermaid 源码**（```` ```mermaid ```` 围栏即源码）：
   GitHub、VS Code、多数 Web 界面都能直接渲染，**不需要任何构建步骤**
   —— 与本项目"零构建前端"的取舍一致。

## 本套文档的取证纪律（写给下一个会话）

* 每个数字都要能**一条命令复算**出来；复算入口就是上面的脚本。
* 引用代码写 `` `相对路径:行号` ``（相对仓库根 `D:\Photoos`）。
* 代码注释里声称的性能数字，**只能转述为"代码声称"**，不得改写成"实测"。
* 行数统计必须用**真实换行符计数**：本仓库换行符不统一，
  用 `Get-Content | Measure-Object -Line` 会**少算**（实测 `index.html` 少算 92 行）。
